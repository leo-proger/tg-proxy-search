# Telegram Proxy Search

Получить MTProto-прокси можно двумя способами:

1. Взять сырой список опубликованных прокси из [
   `proxies.txt`](https://raw.githubusercontent.com/leo-proger/tg-proxy-search/main/proxies.txt) — VPN и установка
   программы не нужны.
2. Самостоятельно спарсить Telegram-канал и проверить найденные прокси с помощью программы.

## Готовый список

В [`proxies.txt`](https://raw.githubusercontent.com/leo-proger/tg-proxy-search/main/proxies.txt) находятся до 1000
последних уникальных прокси, опубликованных в Telegram-канале ([@ProxyMTProto](https://t.me/ProxyMTProto)). Список обновляется каждые два часа.

Одна строка — одна готовая ссылка, которую можно открыть в Telegram:

```text
tg://proxy?server=example.org&port=443&secret=...
```

Это сырой список: все найденные при парсинге прокси попадают в файл без проверки доступности. Некоторые из них могут
быть недоступны.

Любой отдельный прокси из списка можно проверить командой:

```bash
uv run python diagnose.py "tg://proxy?server=...&port=...&secret=..."
```

Чтобы проверить сразу несколько прокси, запустите основную программу и выберите публичный `proxies.txt` в качестве
источника. Перед каждой проверкой программа автоматически скачивает свежую версию списка.

## Самостоятельный поиск

Программа парсит публичный Telegram-канал [@ProxyMTProto](https://t.me/ProxyMTProto), проверяет доступность найденных
прокси и выводит результат.

Для парсинга канала нужен VPN. Во время проверки прокси VPN нужно выключить, чтобы соединение проверялось с вашего
обычного IP.

### Установка

Понадобятся Python 3.13+ и [uv](https://github.com/astral-sh/uv).

```bash
git clone https://github.com/leo-proger/tg-proxy-search.git
cd tg-proxy-search
uv sync
```

### Авторизация в Telegram

Для проверки прокси из публичного `proxies.txt` авторизация не нужна.

Если вы хотите самостоятельно парсить Telegram-канал, авторизуйте Telethon-сессию один раз. Настраивать собственные
`API_ID` и `API_HASH` необязательно: программа использует встроенные значения.

```bash
uv run python -c "
from telethon.sync import TelegramClient
from tg_proxy_search import Config
config = Config.from_env()
with TelegramClient('telethon', config.api_id, config.api_hash) as client:
    client.start()
    print('Готово')
"
```

Введите номер телефона, код из Telegram и пароль двухэтапной аутентификации, если он включён.

### Запуск

```bash
uv run python main.py
```

Сначала программа предложит выбрать источник:

1. Спарсить свежие прокси из Telegram-канала — потребуется VPN и авторизованная Telethon-сессия.
2. Скачать свежий публичный `proxies.txt` — VPN и авторизация в Telegram не нужны.

Для любого источника можно найти заданное количество прокси, успешно прошедших проверку. Также можно проверить всю
доступную выборку: посты за выбранный период для Telegram-канала или весь публичный список.

Пункт повторной проверки кэша появляется только для Telegram-источника и только когда в кэше уже есть успешно
проверенные прокси.

Следуйте подсказкам программы о включении и выключении VPN.
