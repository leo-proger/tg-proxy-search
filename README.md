# Telegram Proxy Search

Программа находит рабочие MTProto-прокси для Telegram и выдаёт готовые ссылки для подключения.

Самый простой способ — использовать публичный `proxies.txt`. Программа сама скачает актуальный список, проверит
прокси и покажет только рабочие. Перебирать список вручную не нужно. Для этого режима не нужны ни VPN, ни авторизация в
Telegram.

## Как выглядит работа программы

Ниже показан основной сценарий: найти три рабочих прокси из публичного списка.

```bash
uv run python main.py
```

После запуска диалог с программой выглядит одинаково:

```text
Откуда взять прокси?
  1  Спарсить свежие из Telegram-канала (нужен VPN)
  2  Скачать из публичного proxies.txt (VPN не нужен)
     Последнее обновление: 12.09.2026 14:30

Источник [1/2]: 2

Что сделать?
  1  Найти N рабочих прокси
  2  Проверить весь публичный список
  3  Обновить локальный proxies.txt

Действие [1/2/3]: 1
Сколько прокси найти? 3

── Шаг 1: скачивается публичный список
  Кандидатов загружено: 560

── Шаг 2: проверяется
  VPN должен быть ВЫКЛЮЧЁН (подключение идёт с вашего реального IP)

  ✓ proxy-one.example:443
  ✗ proxy-two.example:443
  ✓ proxy-three.example:443
  ✓ proxy-four.example:443

  Рабочих: 3  (проверено 4/560)

── Результат  (ссылки вставлять в браузер)

  tg://proxy?server=proxy-one.example&port=443&secret=...
  tg://proxy?server=proxy-three.example&port=443&secret=...
  tg://proxy?server=proxy-four.example&port=443&secret=...
```

Количество загруженных и проверенных прокси меняется со временем. Если вы запросили три рабочих прокси, программа
остановит проверку, как только найдёт их.

## Установка

Понадобится Python 3.13 или новее.

Для запуска и установки зависимостей используется `uv`. Команда установки показана ниже.

Установите `uv` через `pip`, скачайте проект и установите его зависимости.

**macOS и Linux:**

```bash
python3 -m pip install uv
git clone https://github.com/leo-proger/tg-proxy-search.git
cd tg-proxy-search
uv sync
```

**Windows PowerShell:**

```powershell
python -m pip install uv
git clone https://github.com/leo-proger/tg-proxy-search.git
cd tg-proxy-search
uv sync
```

Запустите программу с выключенным VPN.

```bash
uv run python main.py
```

Для самого простого варианта выберите:

1. `2` — скачать прокси из публичного `proxies.txt`;
2. `1` — найти заданное количество рабочих прокси;
3. введите, сколько рабочих прокси нужно найти.

В конце программа напечатает ссылки вида `tg://proxy?...`. Вставьте ссылку в браузер, чтобы открыть её в Telegram и
подключить прокси.

## Что такое proxies.txt

[`proxies.txt`](https://raw.githubusercontent.com/leo-proger/tg-proxy-search/main/proxies.txt) — это публичный список
прокси, найденных в Telegram-канале [@ProxyMTProto](https://t.me/ProxyMTProto). Он обновляется автоматически каждые два
часа и содержит до 1000 последних уникальных ссылок.

Прокси в этом файле ещё не проверены с вашего подключения: часть из них могла перестать работать или быть недоступна
у вашего интернет-провайдера. Поэтому программа использует файл как источник адресов и сама проверяет их перед тем,
как показать результат.

При выборе публичного списка программа перед каждой проверкой скачивает его свежую версию из GitHub. Обновлять
локальный `proxies.txt` для этого не требуется.

Чтобы обновить локальный `proxies.txt` через интерфейс программы:

1. запустите `uv run python main.py`;
2. выберите `2` — публичный `proxies.txt`;
3. выберите `3` — обновить локальный файл.

Программа сначала целиком скачает и проверит формат нового списка. Если скачивание завершится ошибкой, старый файл
останется без изменений. В меню всегда показаны дата и время последнего обновления локального `proxies.txt`.

Альтернативно локальный файл можно обновить вместе со всем проектом:

```bash
git pull
```

Также можно открыть `proxies.txt` по ссылке выше и попробовать отдельный прокси вручную, но программа обычно удобнее:
она сразу отбрасывает недоступные варианты.

## Поиск свежих прокси в Telegram-канале

Это дополнительный режим для тех, кто хочет получить прокси непосредственно из новых сообщений канала, не дожидаясь
следующего обновления публичного списка.

Работа проходит в два этапа:

1. С включённым VPN программа читает канал и собирает опубликованные прокси.
2. Затем вы выключаете VPN, и программа проверяет их с вашего обычного IP.

Программа сама остановится между этапами и подскажет, когда переключить VPN.

### Авторизация в Telegram

Для чтения канала нужно один раз авторизовать Telethon-сессию. Собственные `API_ID` и `API_HASH` необязательны:
по умолчанию используются встроенные значения.

```bash
uv run python -c "
from telethon.sync import TelegramClient
from tg_proxy_search import Config
config = Config.from_env()
with TelegramClient('telethon', config.api_id, config.api_hash) as client:
    client.start()
    print('Готово')
"
```

Введите номер телефона, код из Telegram и пароль двухэтапной аутентификации, если он включён. После успешной
авторизации в папке проекта появится файл `telethon.session`.

Теперь запустите основную программу: `uv run python main.py`.

Выберите источник `1` и следуйте подсказкам о включении и выключении VPN.

## Доступные действия

Для публичного `proxies.txt` доступны три действия:

- найти заданное количество рабочих прокси;
- проверить весь публичный список;
- обновить локальный `proxies.txt`.

Для Telegram-канала можно:

- найти заданное количество рабочих прокси;
- проверить все прокси из постов за последние несколько часов;
- повторно проверить ранее найденные рабочие прокси из кэша, если они уже есть.

Результаты проверок сохраняются в `proxy_cache.json`. Благодаря этому программа не тратит время на слишком
частую повторную проверку тех же адресов.

## Необязательные настройки

Все настройки уже имеют подходящие значения по умолчанию. Если их нужно изменить, создайте `.env` из примера.

**macOS и Linux:**

```bash
cp .env.example .env
```

**Windows PowerShell:**

```powershell
Copy-Item .env.example .env
```

| Переменная | По умолчанию | Для чего нужна |
|---|---:|---|
| `API_ID` | встроенное значение | Личный Telegram API ID |
| `API_HASH` | встроенное значение | Личный Telegram API Hash |
| `TCP_TIMEOUT` | `15` | Сколько секунд ждать ответа от одного прокси |
| `PROXY_CHECK_CONCURRENCY` | `8` | Сколько прокси проверять одновременно |
| `MAX_SCAN_MESSAGES` | `1000` | Сколько сообщений канала просмотреть за один запуск |
| `PROXY_WORKING_RECHECK_HOURS` | `48` | Через сколько часов снова проверять рабочий прокси |
| `PROXY_FAILED_RECHECK_HOURS` | `24` | Через сколько часов снова проверять нерабочий прокси |
| `AUTO_ADD_TO_TELEGRAM` | `false` | По очереди открывать найденные прокси в Telegram |

## Диагностика отдельного прокси

Если Telegram показывает прокси как рабочий, а программа — как нерабочий, выключите VPN и запустите диагностику.

```bash
uv run python diagnose.py "tg://proxy?server=...&port=...&secret=..."
```

Эта команда нужна для поиска проблем и не использует сохранённый результат из кэша.
